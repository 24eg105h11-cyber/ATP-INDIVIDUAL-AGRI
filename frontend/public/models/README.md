# 3D Models Directory

Place your custom 3D Farmer model here:
`frontend/public/models/farmer.glb`

Supported formats: `.glb` or `.gltf`.

If `farmer.glb` is present, AgriTrade's `FarmerModel` 3D component will automatically load it.
If no GLB file is present, the app gracefully renders a stylized 3D procedural Farmer character avatar with floating tablet and bio-luminescent sprout animations.
